# UI Surfaces

Mapa canônico das superfícies de interface do produto.

Este documento incorpora o conteúdo antes mantido em `docs/legacy/UI_MODULES.md`.

---

## Core Surfaces

### Admin / Backoffice

- hotel registry
- space registry
- room registry
- kitchen registry
- table registry
- user and role management

### Event Management

- event form
- event periods
- event configuration
- event-specific space usage

### Occupancy

- guest groups
- reservations
- room allocation timeline
- table allocation by period
- special requests

### Schedule

- agenda view
- day view
- filters by category, location and audience
- religious schedule

### Operations Dashboard

- current alerts
- tasks by priority
- room turnover status
- current activities
- staffing visibility

### Staff PWA

- my current tasks
- next tasks
- overdue tasks
- complete task
- report issue

### Supervisor Dashboard

- team workload
- task board
- task reassignment
- bottleneck visibility

### Kashrut

- mashguichim shifts
- kitchen coverage
- checklist execution
- kasherization tasks

### Logistics

- deliveries list
- equipment list
- movement log

### Lost & Found

- item registration
- search and filter
- claim handling
